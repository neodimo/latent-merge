## V0 Contract

Latent Merge is a foreground-preserving harmonization/relighting tool for VFX comp.

```
CG RGBA + plate + alpha/matte -> adjusted CG foreground + diagnostics -> trusted A-over-B composite in Nuke
```

The plate is not repainted. The only allowed plate-adjacent outputs are explicit, inspectable interaction passes such as contact shadow, edge spill, reflection, or shadow contribution. The primary model output is adjusted foreground, not a flattened AI composite.

## First Success Case

One low-resolution still or short proxy sequence must run end-to-end with:

- input CG RGBA
- input plate RGB
- alpha/matte
- optional AOVs only if already available
- output adjusted foreground
- output final comp generated by normal A-over-B over untouched plate
- output delta/debug passes

Target resolution for the first proof is 512-1024 px crop/proxy. Full-resolution EXR/ACEScg support is a later gate, not a blocker for the first smoke pipeline.

Phase 0 gate, Sun 2026-05-24 EOD:

- one golden fixture committed or staged in a known folder
- exact input/output filenames documented
- model access path selected or explicitly blocked with owner and ETA
- smoke pipeline runs on the golden fixture

Phase 1 gate, Sun 2026-05-31 EOD:

- real ingest -> merge -> output path runs on the golden fixture
- reproducible config and structured logs are saved
- intermediates include adjusted foreground, final comp, delta, and alpha-weighted delta
- plate remains byte/visually untouched outside explicit interaction passes
- a non-author can reproduce the golden output from a clean checkout using README instructions only
- scaffold runner exists before model integration, with the real model added behind a named backend instead of changing output filenames

Phase 2 gate, Sun 2026-06-07 EOD:

- exactly 10 varied cases tested
- at least one short proxy sequence tested for flicker
- numeric runtime, memory, and output variance/flicker baselines committed
- known-fail list is explicit
- single user surface chosen and locked: CLI, notebook, or Nuke-facing service

Alpha gate, Sun 2026-06-14 EOD:

- chosen surface runs without manual internal edits
- basic validation catches missing CG, plate, alpha, bad dimensions, and unsupported formats
- progress and cancel/retry behavior exist where the chosen surface supports it
- debug outputs remain inspectable
- target repo/workflow integration and rollback path are documented
- third party completes an end-to-end run from README alone
- no UI/product polish is accepted as a substitute for model/pipeline proof

Audit-ready gate, Fri 2026-06-19 EOD:

- fresh-machine or fresh-environment install test passes
- regression suite passes on the golden fixture set
- benchmarks documented
- known limitations documented
- packaged artifact or runnable repo instructions exist
